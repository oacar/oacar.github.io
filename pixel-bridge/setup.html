Pixel Bridge

Setup guide

Install both apps, pair once, and let the watch connect directly to Apple's notification service.

Pixel Bridge is a private preview. These steps apply only to the builds provided by the developer.

Before you start

  1. Install the Pixel Bridge companion on the iPhone.
  2. Install Pixel Bridge on the Pixel Watch.
  3. Turn on Bluetooth on both devices and keep them close together.
  4. Allow Bluetooth access on the iPhone.
  5. Allow nearby-device and notification access on the watch.

Pair the devices

  1. Open Pixel Bridge on the iPhone and tap Start pairing.
  2. Open Pixel Bridge on the watch and tap Find iPhone.
  3. Accept the system pairing prompts on both devices.
  4. Wait until the watch reports Connected.
  5. On the iPhone, open Settings → Bluetooth, select the paired watch accessory, and enable Share System Notifications.
  6. Send a test notification while the iPhone is locked.

After setup, you can tap Stop pairing on the iPhone. This stops discovery but keeps the existing bond.

If notifications do not appear

  • Confirm that both devices have Bluetooth enabled and are within range.
  • Confirm that Share System Notifications remains enabled in iPhone Bluetooth settings.
  • Check the iPhone's notification and preview settings for the source app. Pixel Bridge cannot reveal details that iOS withholds.
  • Confirm that Pixel Bridge has notification permission on the watch.
  • Wait up to two minutes after returning to Bluetooth range.

If the watch reports a stale bond

  1. Use Reset connection in the watch app.
  2. Remove the old Pixel Bridge or watch accessory pairing from Bluetooth settings on both devices.
  3. Restart pairing from the iPhone app.

Reset connection removes Pixel Bridge's encrypted reconnect target. It does not silently remove the system Bluetooth bond.

If automatic recovery fails

Open both apps and check their connection states. If retry does not work, use the stale-bond steps above. For support, send only the displayed state and sanitized reason code. Do not send notification content, raw Bluetooth logs, addresses, or device identifiers.
